## 🔥 四大殺手級黑科技（最強特色）

### 📸 1. 手機拍照 ➔ 秒貼電腦操作中的軟體
* **免傳檔、免登入通訊軟體**：手機/iPad 掃描條碼連線後隨手一拍，照片會在 **0.5 秒內自動貼上（Ctrl+V）到您電腦目前正在操作的軟體**（如 PowerPoint、Word、電子白板、網頁、LINE 等）！
* **即時投影學生作業**：走下講台巡視課堂，隨拍學生紙本作業或優秀筆記，電腦螢幕立即同步呈現。

### 🎙️ 2. 手機語音輸入 ➔ 電腦游標處秒打字
* **人在講台漫步，文字秒上電腦**：點擊手機麥克風說話，手機辨識出的文字會在點擊送出的瞬間，**直接打在電腦游標所在的任何輸入框內**！
* **免滑動緊湊鍵盤介面**：專為 iPad/手機最佳化（88px 高度、右側大發送鈕、獨立全形標點符號），支援「傳送後自動按 Enter」，遠端操控輸入超流暢。

### ✂️ 3. 螢幕截圖 ➔ 智慧去背 ＆ 一鍵「貼回前一個軟體」
* **教材圖片製作神器**：電腦螢幕框選截圖後，具備 0%~100% 智慧去背滑桿與「🎨 全螢幕放大精細編輯器」（6 種尺寸透明橡皮擦與畫筆）。
* **⚡ 一鍵貼回前一個軟體**：去背完成後免切換視窗、免按 Ctrl+V，點擊 **「⚡ 貼回前一個軟體」** 即可自動將透明去背圖秒貼回剛才操作的 PPT、Word 或白板！

### 📷 4. 全能「實物投影機 ＆ 教材展示台」✕「👤 講師浮動鏡頭」（NEW!）
* **外接攝影機即時教學**：支援多鏡頭切換（#1/#2/#3）、90° 旋轉、水平鏡射、垂直翻轉、空白鍵畫面凍結、滾輪 1x~4x 放大與右鍵平移；進入 `F11` 全螢幕展示時，頂部依然常駐所有基本調整工具！
* **☀️ 智慧補光／考卷清晰化**：針對教室光線偏暗或紙本陰影，一鍵自動提亮紙張背景並強化黑字對比，亦可微調亮度與對比。
* **🖊️ 內建畫筆、螢光筆與橡皮擦**：提供 6 色畫筆與**半透明亮色螢光筆（畫重點完全不遮蓋課本文字）**，書寫筆跡在框選存檔或貼回前軟體時會連同畫面一併輸出！
* **💾 選取範圍即時存檔（含語音播報）**：左鍵框選教材局部範圍後，可點 **「⚡ 貼回前軟體」**（支援自動去背），或點 **「💾 選取範圍即時存檔」** 免詢問直接存入指定資料夾，存檔完成自動播放提示音並語音播報 **「存檔完畢」**！
* **📂 教材圖片資料夾翻頁展示**：可直接載入圖片資料夾，全視窗/全螢幕透過左右方向鍵快速翻頁講解。
* **👤 講師浮動鏡頭（置頂外框 PiP）**：一鍵切換為置頂無邊框講師小視窗（可拖曳、滾輪調大小），內建圓形、圓角方框、金牌講台、汪汪耳朵外框，更支援 **「🖼️ 上傳去背圖片自動抓外框」** 打造個人專屬直播與線上課外框！
